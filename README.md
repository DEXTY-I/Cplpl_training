# 🚀 C++ CheatSheet & Practice Lab

Привет! 👋 Этот репозиторий создан для всех, кто сейчас осваивает C++ и хочет не просто переписывать код из лекций, а **понимать каждую строчку**.

Здесь собраны примеры кода по темам нашей учебной программы с максимально подробным разбором алгоритмов, встроенных функций и синтаксических конструкций.

---

## 🎯 Зачем этот репозиторий?

* **Понимание вместо заучивания:** Каждый пример снабжён развернутыми комментариями к ключевым функциям.
* **Быстрый повтор:** Удобная база для подготовки к лабораторным, практикам и зачётам.
* **Чистый код:** Примеры написаны с соблюдением базовых стандартов C++ (Modern C++ practices).

---

## 📚 Структура репозитория

Модули разбиты по темам от базовых концепций к более сложным:

```
├── 01_Basics/            # Ввод/вывод, типы данных, ветвления
├── 02_Pointers_Refs/     # Указатели, ссылки, работа с памятью
├── 03_Functions/         # Передача по ссылке/значению, перегрузка
├── 04_OOP_Intro/         # Классы, инкапсуляция, конструкторы
└── README.md
```

*(Структура будет дополняться и меняться по мере прохождения материала, сейчас я пишу блок №1)*

---

## 🛠 Как работать с материалом?

1. Перейдите в нужную папку с темой.
2. Откройте файл `.cpp` — внутри вы найдёте рабочий код с детальным объяснением того, что происходит на каждом этапе.
3. Склонируйте репозиторий и попробуйте запустить примеры локально:

```bash
git clone https://github.com/DEXTY-I/Cplpl_training.git
```
